# Code Game

A basic MonoGame project created with the MonoGame Cross-Platform Desktop Application template.

## Prerequisites

- .NET SDK 9.0 or later
- MonoGame Framework

## Building and Running

- Build: `dotnet build`
- Run: `dotnet run`

Or use VS Code tasks:
- Ctrl+Shift+P > Tasks: Run Task > build
- Ctrl+Shift+P > Tasks: Run Task > run

## Project Structure

- `Program.cs`: Entry point
- `Game1.cs`: Main game class
- `Content/`: Game assets
- `Icon.bmp`, `Icon.ico`: Icons

## Next Steps
